MedSupAPP — Project Summary
LAST UPDATED: 2026-05-29

================================================================================
OVERVIEW
================================================================================
Name:        medsupapp
Framework:   Next.js 16.2.6 (App Router), React 19, TypeScript
Hosting:     Vercel (region sfo1) — canonical https://www.medsupapp.com.br (apex redirects to www)
Purpose:     Practice management for Brazilian doctors/clinics (agenda, finance,
             patients, WhatsApp, LGPD-friendly split: PHI on Google Drive,
             operational data in Supabase)
Auth:        Google OAuth only (NextAuth v5); email/password signup disabled
Email flow:  4-digit verification after Google login (Resend)
Messaging:   wa.me manual links + optional Meta WhatsApp Cloud API queue

================================================================================
AUTH & SECURITY
================================================================================
- Middleware checks google_account_access.email_verified for protected routes
- Legacy routes (/register, /auth/cadastro, /auth/verify-code) redirect to /login
- Public: /, /login, /f/*, /api/whatsapp/webhook, cron /api/whatsapp/process
- Do NOT add a custom app/api/auth/session route (conflicts with Auth.js)
- Server Google tokens: GET /api/auth/tokens (requires verified email)

================================================================================
DATA MODEL (Supabase — operational)
================================================================================
- google_account_access — Google sub, email, verification, tokens metadata
- onboarding_profiles — clinic/doctor profile after verification
- verification_codes — email OTP storage
- whatsapp_fila — outbound message queue
- financeiro / agenda-related tables (see sql/)

Clinical/patient files: user's Google Drive (not in Supabase).

================================================================================
WHATSAPP
================================================================================
Manual: lib/whatsapp.ts builds wa.me URLs in UI.
Automatic: WHATSAPP_* env vars → enqueue → cron GET /api/whatsapp/process
Webhook: POST/GET /api/whatsapp/webhook (WHATSAPP_VERIFY_TOKEN)
Docs: docs/WHATSAPP_BUSINESS_SETUP.md

================================================================================
ENVIRONMENT (see .env.example)
================================================================================
Required: Supabase URL/keys, Google OAuth, NEXTAUTH_SECRET, AUTH_URL,
          RESEND_API_KEY (for verification email)
WhatsApp: WHATSAPP_TOKEN, WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_VERIFY_TOKEN,
          CRON_SECRET (+ template names when approved)
CLI: SUPABASE_ACCESS_TOKEN for npm run db:*
